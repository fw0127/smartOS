# 02 架构设计

## 1. 分层与抽象边界

```
┌──────────────────────────────────────────────────────────┐
│  应用层:任务(业务逻辑,内核不关心其内容)                    │
├──────────────────────────────────────────────────────────┤
│  smartOs 内核(纯可移植 C,无任何平台依赖)                   │
│   sched 调度 │ time 抽象时间 │ event 事件 │ ring 环形缓冲   │
│   supervise 监控 │ error 错误 │ cfg 配置根(由生成器产生)     │
├════════════════════ 平台能力契约 ════════════════════════════┤
│   时间源 │ 互斥区 │ 等待 │ 健康信号 │ 安全停机                │
├──────────────────────────────────────────────────────────┤
│  平台适配(每个目标一份,内核之外)                            │
│   主机模拟 │ 裸机 MCU │ RTOS 线程 │ ……                       │
└──────────────────────────────────────────────────────────┘
```

**唯一的抽象边界是"平台能力契约"**(05 篇)。契约之上的一切对所有平台完全相同;契约之下的一切内核不可见。

### 依赖规则

1. 内核只包含自身头文件和契约头文件 `sos_platform.h`,以及 C 标准的 `stdint.h` / `stdbool.h` / `stddef.h`。
2. 内核不使用编译器扩展、内联汇编、特定字节序或特定对齐假设。
3. 任务只依赖内核公共头 `sos_pub.h`;任务之间不直接调用,只通过事件或任务自定义的共享数据交互。
4. 平台适配可以依赖任何东西,但只通过契约函数被内核调用。

## 2. 内核模块

| 模块 | 职责 | 依赖的平台能力 |
|---|---|---|
| `sched` | 校验配置根、就绪位图与最高优先级查找、`AGAIN` 让出、派发、生命周期管理 | 等待 |
| `time` | 抽象时间读取、差值、超时判断、单位换算 | 时间源 |
| `event` | 每任务事件位的置位 / 原子取出,同步维护就绪位图 | 互斥区、等待(notify) |
| `ring` | SPSC 环形缓冲,可绑定消费者事件 | 互斥区 |
| `supervise` | 执行时间预算、存活监控、健康信号决策 | 时间源、健康信号 |
| `error` | 错误码、错误记录、`sos_fatal` | 安全停机 |
| `cfg` | 配置根:任务表、缓冲表、钩子函数指针表、版本与摘要;由 `sosgen` 根据描述文件产生 | — |

## 3. 抽象概念词汇表

本项目文档统一使用以下抽象术语,不使用任何具体硬件术语:

| 术语 | 定义 |
|---|---|
| **tick** | 时间源的计数单位,物理时长由平台给出的速率决定 |
| **异步上下文** | 任何可能打断任务执行的执行流:中断、信号处理函数、其他线程等 |
| **互斥区** | 一段不会被异步上下文打断的代码区间 |
| **健康信号** | 内核向外界声明"系统仍在正常调度"的动作;可映射到看门狗、心跳输出、外部监控进程,也可为空 |
| **安全停机** | 不再返回的终止动作;平台决定其含义(复位、停机、退出进程、跳回测试框架) |
| **步** | 任务 `run` 函数的一次调用,必须有界且非阻塞 |

## 4. 目录结构(规划)

```
smartOs/                            独立仓库(D6)
├── README.md / CHANGELOG.md / LICENSE(MPL-2.0)
├── docs/                           设计文档
├── kernel/                         ← 与平台无关,所有目标共用同一份
│   ├── inc/
│   │   ├── sos_pub.h               对外唯一头文件
│   │   ├── sos_types.h             基础类型、返回码、钩子表与配置根结构
│   │   └── sos_error.h             错误码
│   └── src/
│       ├── sos_sched.c / sos_sched_pri.h
│       ├── sos_bitmap.c            最低置位查找(可移植实现)
│       ├── sos_time.c
│       ├── sos_event.c
│       ├── sos_ring.c
│       ├── sos_supervise.c
│       └── sos_error.c
├── platform/
│   ├── sos_platform.h              平台能力契约(内核唯一的向下依赖)
│   ├── host/                       虚拟时间平台 + 线程平台,仅用于测试
│   └── contract_tests/             契约一致性测试
├── tools/
│   └── sosgen/                     描述文件 → 配置根的生成器,仅以源码提供(06 篇)
├── examples/
│   ├── periodic_minimal/           一个周期任务的最小示例
│   ├── layered_pipeline/           两级流水线示例(含环形缓冲)
│   └── manual_cfg/                 不使用生成器的手写配置示例
└── test/                           单元、场景、并发、生成器测试
```

真实目标平台的适配不在本仓库中,由使用方实现(05 篇第 3 节)。

## 5. 命名规范

| 项 | 规则 | 示例 |
|---|---|---|
| 内核公共函数 | `sos_<模块>_<动作>` | `sos_event_set`、`sos_time_now` |
| 平台契约函数 | `sos_platform_<动作>` | `sos_platform_now`、`sos_platform_halt` |
| 类型 | `sos_<名称>_t` | `sos_task_desc_t`、`sos_tick_t` |
| 宏 / 常量 | `SOS_<名称>` | `SOS_RUN_OK`、`SOS_TRIG_PERIODIC` |
| 文件内私有 | `static`,前缀 `l_` | `l_select_next` |
| 头文件 | `_pub.h` 对外 / `_pri.h` 私有 / `_cfg.h` 配置 | `sos_sched_pri.h` |
| 生成的常量 | `SOS_TASK_<任务>`、`SOS_EV_<任务>_<事件>`、`SOS_RING_<缓冲>` | `SOS_EV_WORKER_REQ_READY` |

## 6. 语言与编码约束

- C99,无标准库依赖(仅类型头文件)。
- MISRA C:2012 友好:无递归、无动态内存、无可变参数函数。
- 单执行流:所有任务在同一个调用栈上依次执行,栈深 = 最深任务调用链 + 异步上下文的占用(由平台决定)。
- 异步上下文只允许调用 `sos_event_set_async` 和 `sos_ring_put`(作为声明过的生产者)。
