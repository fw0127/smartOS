# 04 接口规格

> 只描述接口名称、参数、语义与调用约束,不含实现。应用只需包含 `sos_pub.h` 和生成器产生的 `sos_cfg_gen.h`。
> 本篇所有接口与平台无关;平台侧接口见 05 篇。

## 1. 基础类型

| 类型 | 说明 |
|---|---|
| `sos_tick_t` | 无符号整数,宽度 = `SOS_PLATFORM_TICK_BITS`;内核内部时间 |
| `sos_time_t` | 32 位无符号整数,单位 `SOS_TIME_UNIT`;配置与 API 中使用的平台无关时间 |
| `sos_events_t` | 32 位事件位集合;最高位保留为 `SOS_EV_ALARM` |
| `sos_task_id_t` | 任务标识;由生成器产生具名常量(如 `SOS_TASK_WORKER`) |
| `sos_ring_t` | 环形缓冲句柄(不透明);由生成器产生具名实例 |
| `sos_run_result_t` | `SOS_RUN_OK` / `SOS_RUN_AGAIN` / `SOS_RUN_STOP` / `SOS_RUN_ERR` |
| `sos_status_t` | `SOS_OK` / `SOS_E_PARAM` / `SOS_E_STATE` / `SOS_E_CFG` / `SOS_E_FULL` / `SOS_E_EMPTY` / … |
| `sos_hooks_t` | 钩子函数指针表(第 9 节) |
| `sos_cfg_root_t` | 配置根对象:任务表、环形缓冲表、钩子表、版本与摘要(由生成器产生) |

## 2. 任务回调

| 回调 | 参数 | 返回 | 约束 |
|---|---|---|---|
| `init` | `ctx` | `sos_status_t` | 启动或重启时调用;可为空 |
| `run` | `ctx`,本次取出的 `events` | `sos_run_result_t` | 非阻塞、有界;不得调用 `sos_start` |
| `done` | `ctx` | 无 | 释放任务持有的资源;可为空 |

## 3. 内核生命周期

| 接口 | 语义 | 调用时机 |
|---|---|---|
| `sos_init(root)` | 校验配置根(ABI 版本、结构、时间范围)、初始化运行时状态与环形缓冲、调用各任务 `init`;返回 `SOS_OK`,配置无效时返回 `SOS_E_PARAM` / `SOS_E_CFG`(此时不启动任何任务);任务 `init` 失败按其错误策略处理 | 平台准备完成后调用;可重复调用以整体重新初始化 |
| `sos_init_checked(root, digest)` | 先要求 `root->digest == digest`,不等则返回 `SOS_E_CFG`;再执行 `sos_init`(D14) | 生成的配置通过宏 `SOS_CFG_INIT()` 调用:宏在应用的编译单元里展开,带入头文件中的摘要,与 `.c` 表格里写死的摘要比对,从而拒绝"头文件与表格来自不同次生成"的组合 |
| `sos_start()` | 进入调度主循环,**不返回**;等价于循环调用 `sos_poll`,空闲时调用 `on_idle` 钩子和平台等待 | `sos_init` 成功后 |
| `sos_poll(&deadline)` | 执行**一次**调度迭代,从不等待:派发一步返回 `SOS_POLL_RAN`;无事可做返回 `SOS_POLL_IDLE` 并给出下一个截止时刻;未初始化返回 `SOS_POLL_NOT_INIT` | 不用 `sos_start` 时,由宿主循环调用(D10) |
| `sos_fatal(code)` | 记录 → 钩子 `on_fatal` → 平台安全停机,**不返回** | 任务上下文 |
| `sos_version()` | 返回内核版本号(主.次.修订) | 任意 |

## 4. 任务控制(任务上下文)

| 接口 | 语义 |
|---|---|
| `sos_task_self()` | 当前运行任务的 id |
| `sos_task_set_alarm(delay)` | 给自己设一次性闹钟,到期置 `SOS_EV_ALARM`;重复调用覆盖 |
| `sos_task_cancel_alarm()` | 取消闹钟 |
| `sos_task_stop(id)` | 停止某任务(调用其 `done`),在下次派发前生效 |
| `sos_task_restart(id)` | `done` → `init`,重置运行时状态 |
| `sos_task_get_stats(id, out)` | 读取 `state / max_step / overrun_cnt / miss_cnt / restart_cnt` |

## 5. 事件

| 接口 | 可调用的上下文 | 语义 |
|---|---|---|
| `sos_event_set(id, bits)` | 任务 | 置事件位;若命中 `event_mask` 则置就绪位 |
| `sos_event_set_async(id, bits)` | 任意,含异步上下文 | 同上,内部使用互斥区并调用平台 `notify` |
| `sos_event_peek(id)` | 任务 | 读取但不清除(调试用) |

事件在派发时由内核原子地取出并清零,作为 `run` 的参数传入。事件位名称由生成器按任务产生(如 `SOS_EV_WORKER_REQ_READY`)。

## 6. 环形缓冲

| 接口 | 调用者 | 语义 |
|---|---|---|
| `sos_ring_put(ring, elem)` | 唯一的生产者(可为异步上下文) | 拷入一个元素;满时返回 `SOS_E_FULL` 并增加溢出计数;成功且已绑定消费者时自动置事件 |
| `sos_ring_get(ring, out)` | 唯一的消费者任务 | 取出一个元素;空时返回 `SOS_E_EMPTY` |
| `sos_ring_peek(ring, out)` | 消费者任务 | 读取队首但不取出 |
| `sos_ring_count(ring)` | 任意 | 当前元素数(可能立即过时,仅作参考) |
| `sos_ring_get_stats(ring, out)` | 任意 | 容量、最高水位、溢出次数 |

原地访问接口(零拷贝,D8;规则见 03 篇 6.2.1):

| 接口 | 调用者 | 语义 |
|---|---|---|
| `sos_ring_reserve(ring)` | 生产者(可为异步上下文) | 返回空槽指针;满时返回空指针并增加溢出计数;未提交前重复调用返回同一槽 |
| `sos_ring_commit(ring)` | 生产者 | 发布已写入的槽;已绑定消费者时自动置事件;无未完成预留时返回 `SOS_E_STATE` |
| `sos_ring_acquire(ring)` | 消费者任务 | 返回队首元素指针;空时返回空指针;未归还前重复调用返回同一元素 |
| `sos_ring_release(ring)` | 消费者任务 | 归还队首槽位;无未完成取用时返回 `SOS_E_STATE` |

约束:每个缓冲恰好一个生产者执行流和一个消费者任务,在描述文件中声明;违反该约束的行为未定义。同一端在原地操作未完成时不得混用按值接口。

描述符字段 `producer` / `consumer` 记录归属任务(`SOS_TASK_NONE` 表示异步上下文或未声明);归属任务停止或重启时,其未完成的 `reserve` / `acquire` 由内核放弃(D11,03 篇 6.2.1)。`sos_init` 检查:归属任务存在、生产者与消费者不同、设置了 `notify` 就必须有消费者。

模块开关(D12):`SOS_CFG_RING_ENABLE = 0` 时整组环形缓冲接口不存在(调用处编译失败,配置中声明缓冲会被 `sos_init` 拒绝);`SOS_CFG_RING_ZERO_COPY = 0` 时只有按值接口。

## 7. 时间

| 接口 | 语义 |
|---|---|
| `sos_time_now()` | 当前 tick |
| `sos_time_to_ticks(t)` / `sos_ticks_to_time(k)` | 配置时间与 tick 互相换算 |
| `sos_time_since(start)` | `now − start`(回绕安全,单位 tick) |
| `sos_time_elapsed(start, dur)` | 从 `start` 起是否已经过 `dur`;用于任务内部超时。**`dur` 与实际经过的时间都必须小于可比较范围**(2^(位宽−1) 个 tick);超出时结果无意义 |

## 8. 互斥区

| 接口 | 语义 |
|---|---|
| `sos_critical_enter()` / `sos_critical_exit()` | 进入/离开互斥区,可嵌套 |

## 9. 钩子:函数指针表(D5)

钩子通过配置根中的 `sos_hooks_t` 提供,而不是依赖工具链的弱符号机制。表中每一项都可以为空,为空时内核执行默认行为。

| 成员 | 调用时机 | 参数 | 默认行为(为空时) |
|---|---|---|---|
| `on_overrun` | 单步超预算 | 任务 id、实际时长 | 无(仅计数) |
| `on_task_error` | 任务返回 `ERR` 或存活失效 | 任务 id、错误码 | 无(仅记日志) |
| `on_fatal` | 安全停机前 | 错误码 | 无 |
| `on_idle` | 进入平台等待前 | 无 | 无 |
| `on_ring_overflow` | 环形缓冲写满被拒绝之后的下一次调度迭代 | 缓冲 id | 无(仅计数)。**v0.5.1 起在调度器上下文中调用**(D15):生产者(可能是中断)只置一个待处理标记;两次调度迭代之间的多次溢出合并为一次调用,确切次数见统计 |

约束:所有钩子都在调度器上下文中被调用(与任务上下文同等),必须短而有界;不得调用 `sos_start` 或 `sos_init`。表本身只读,由生成器根据描述文件产生。

## 10. 调用上下文

三种上下文:**主上下文**(调用 `sos_init` / `sos_poll` 的执行流,不在任何 `run` 之内)、**任务上下文**(`init` / `run` / `done` 与钩子之内)、**异步上下文**(中断、信号处理函数、其他线程)。

| 接口 | 主 | 任务 | 异步 | 备注 |
|---|---|---|---|---|
| `sos_init`、`sos_init_checked` | ✓ | — | — | 不可在任务中重新初始化 |
| `sos_start`、`sos_poll` | ✓ | — | — | 调度器不可重入 |
| `sos_fatal` | ✓ | ✓ | — | 不返回 |
| `sos_task_self`、`sos_task_set_alarm`、`sos_task_cancel_alarm` | — | ✓ | — | 作用于当前任务;闹钟只限前台任务 |
| `sos_task_stop`、`sos_task_restart`、`sos_task_get_stats` | ✓ | ✓ | — | 读写任务状态,不加锁;对当前任务的停止/重启在本步返回后生效 |
| `sos_event_set`、`sos_event_peek` | ✓ | ✓ | — | |
| `sos_event_set_async` | ✓ | ✓ | ✓ | 异步上下文唯一的事件入口 |
| `sos_ring_put`、`reserve`、`commit` | 见备注 | 见备注 | 见备注 | 只能由描述符声明的那**一个**生产者执行流调用(生产者任务,或一个异步上下文) |
| `sos_ring_get`、`peek`、`acquire`、`release` | — | ✓ | — | 只能由消费者任务调用 |
| `sos_ring_count`、`sos_ring_get_stats` | ✓ | ✓ | ✓ | 读取瞬时值 |
| `sos_time_*`、`sos_critical_*` | ✓ | ✓ | ✓ | |
| `sos_error_count`、`sos_error_get` | ✓ | ✓ | — | |

调试辅助:`SOS_CFG_RING_CHECK_OWNER = 1` 时,内核拒绝来自非声明方的环形缓冲调用(返回 `SOS_E_STATE` 或空指针)。生产者为异步上下文时,"不在任何任务中"即视为合法——它无法区分两个不同的中断,单一生产者执行流的约束仍由使用者保证。

## 11. 诊断

| 接口 | 语义 |
|---|---|
| `sos_error_count()` / `sos_error_get(i, out)` | 读取错误日志 |

## 12. 配置

配置不再手写,而是由**描述文件 + 生成器**产生(06 篇)。生成结果:

| 产物 | 内容 |
|---|---|
| `sos_cfg_gen.h` | 任务 id、事件位、环形缓冲句柄的具名常量;配置摘要 |
| `sos_cfg_gen.c` | 排好序的只读任务表、环形缓冲存储、钩子表、配置根对象 `sos_cfg_root` |

内核参数(编译期,`sos_cfg.h`,同样可由描述文件产生):

| 参数 | 默认值 | 含义 |
|---|---|---|
| `SOS_TIME_UNIT` | 1 µs | 配置时间单位 |
| `SOS_CFG_MAX_TASKS` | 32 | 任务总数上限(前台任务另受单字位图限制,≤ 32) |
| `SOS_CFG_MAX_RINGS` | 8 | 环形缓冲上限 |
| `SOS_CFG_ERRLOG_DEPTH` | 8 | 错误日志深度 |
| `SOS_CFG_OVERRUN_IS_ERROR` | 0 | 超预算是否按错误策略处理 |
| `SOS_CFG_HEALTH_ENABLE` | 1 | 是否由内核发出健康信号 |
| `SOS_CFG_HEALTH_MIN_INTERVAL` | 10 ms | 监控检查与健康信号的节拍(配置时间单位) |
| `SOS_CFG_STATS` | 1 | 是否统计 `max_step`、水位等 |
| `SOS_CFG_FIND_FIRST_SET` | 内核可移植实现 | 可选:由平台适配替换为等价的加速实现 |
| `SOS_CFG_RING_ENABLE` | 1 | 编译环形缓冲模块 |
| `SOS_CFG_RING_ZERO_COPY` | = `SOS_CFG_RING_ENABLE` | 编译原地访问接口(需要环形缓冲模块) |
| `SOS_CFG_RING_CHECK_OWNER` | 0 | 调试:检查环形缓冲调用方是否为声明的生产者/消费者(见第 10 节) |
| `SOS_CFG_SUPERVISE_ENABLE` | 1 | 编译监控模块:执行预算、存活监控、健康信号。关闭时配置中的 `alive_window` 会被拒绝(否则会静默失效),`budget` 只作为分析输入;**内核不再发健康信号,平台的看门狗需另行服务** |
